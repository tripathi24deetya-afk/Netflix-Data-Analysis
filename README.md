# Netflix-Data-Analysis
Exploratory Data Analysis on Netflix dataset using Python.# Netflix Data Analysis

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

The goal of this project is to analyze:
- Movies vs TV Shows
- Top genres
- Country-wise content distribution
- Netflix growth over the years

---

## 🛠 Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

---

## 📊 Key Insights
- Movies dominate Netflix content
- USA produces the highest amount of content
- Drama and International genres are the most popular
- Netflix content increased rapidly after 2015

---

## 📁 Dataset
Netflix Movies and TV Shows Dataset from Kaggle.
